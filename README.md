## 📌 Project Overview

**Kingdom Partakers Kamulu — Secure the Sanctuary** is a church fundraising invitation project designed to communicate a vision, invite supporters, and encourage contributions toward securing a permanent place of worship.

The project transforms a traditional fundraising invitation into a clean, accessible, and responsive digital experience using HTML5 and CSS3.

It features a distinctive navy-blue, gold, white, and red visual identity inspired by the original invitation artwork.

## 🎯 Project Objectives

- Present the church's fundraising vision clearly and professionally.
- Highlight the event date and guest of honour.
- Display contribution instructions prominently.
- Communicate the fundraising message and supporting Bible verse.
- Create a responsive layout suitable for desktop, tablet, and mobile screens.
- Demonstrate front-end development and visual design skills.

## ✨ Key Features

- **Premium invitation design** — A bold visual hierarchy with navy, gold, white, and red accents.
- **Church branding** — Dedicated space for the Kingdom Partakers Kamulu identity.
- **Personalised invitation** — A clear invitation area for the intended guest.
- **Fundraising campaign headline** — “Secure the Sanctuary” as the central message.
- **Event information** — Prominent presentation of the event date and guest of honour.
- **Contribution information** — A dedicated section for the approved M-PESA payment details.
- **Scripture section** — A Bible verse reinforcing the spirit of generosity and giving.
- **Responsive layout** — Designed to adapt to different screen sizes.
- **Semantic HTML** — Structured content for maintainability and accessibility.
- **Custom CSS styling** — Consistent typography, spacing, colours, and decorative elements.

## 🎨 Design Direction

The visual design follows a formal church-event identity:

- **Navy blue:** Represents trust, stability, and a formal presentation.
- **Gold:** Adds emphasis and a celebratory fundraising aesthetic.
- **White:** Keeps the layout clear and readable.
- **Red:** Highlights important invitation text and selected details.

The layout prioritises the main fundraising message, event information, contribution details, and scripture so visitors can understand the purpose quickly.

## ♿ Accessibility and Usability

The project aims to support a clear and accessible experience through:

- Meaningful HTML structure and heading hierarchy.
- Readable text and consistent spacing.
- Responsive content for different devices.
- Descriptive alternative text for meaningful images.
- Clearly labelled sections and important event details.

Accessibility should be checked in the finished implementation, particularly colour contrast, keyboard navigation, and text readability on small screens.

## 🔒 Scope and Limitations

This is a **static front-end project** built with HTML and CSS.

- It does not process or verify payments.
- It does not connect to an M-PESA payment API.
- It does not store visitor information or donations.
- Displaying a payment number does not confirm that the number is official or active.
- GitHub Pages hosts static files and does not provide a private payment-processing backend.

All payment details, branding, event information, and names should be verified and approved by the organisers before public distribution.
